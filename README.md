# Affix

Concept website for Affix, a vitamin brand with no pills: a strip that melts on the tongue every morning, and a press-on Stamp for the arm or thigh once a week.

Live: https://jkwon20241.github.io/affix/

Pages: Home, The range (with Build your month), The app (a working phone prototype), About. Plain HTML, CSS and JavaScript; GSAP from cdnjs.

Affix is a concept brand by Jennie Kwon. It is not a real product and makes no health claims.
